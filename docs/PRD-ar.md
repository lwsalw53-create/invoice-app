# وثيقة المنتج (PRD) — مناسك برو

## 1) الرؤية

**مناسك برو** منصة سحابية عربية لإدارة عمليات العمرة والحج للحملات الصغيرة والمتوسطة، بهدف تقليل الأخطاء التشغيلية وتسريع الخدمة ورفع التحصيل المالي.

## 2) الجمهور المستهدف

1. شركات العمرة والحج الصغيرة والمتوسطة.
2. مشرفو التشغيل داخل الحملة.
3. المندوبون الميدانيون في الاستقبال والنقل.
4. المحاسبون وفرق المتابعة المالية.

## 3) القيمة المقدمة

- توحيد إدارة العملاء والحجوزات والمدفوعات في نظام واحد.
- رؤية يومية مباشرة للوصول والمغادرة والالتزامات.
- تقليل التأخير والأخطاء عبر التنبيهات الذكية.
- تحسين التواصل مع العملاء (واتساب/SMS).

## 4) الأدوار والصلاحيات

### Admin (مدير النظام)
- إدارة جميع البيانات والإعدادات.
- إدارة المستخدمين والصلاحيات.
- الاطلاع على التقارير المالية والتشغيلية.

### Operations (مشرف التشغيل)
- إدارة العملاء والحجوزات والباقات.
- توزيع المهام على المندوبين.
- متابعة الرحلات والفنادق.

### Agent (مندوب)
- الاطلاع على قائمة القادمين اليوم.
- تحديث حالة الاستلام والتنفيذ الميداني.
- الوصول لبيانات التواصل السريعة.

### Accountant (محاسب)
- إدارة المدفوعات والتحصيلات.
- متابعة المديونيات.
- إصدار تقارير مالية دورية.

## 5) الصفحات الأساسية

## 5.1 صفحة تسجيل الدخول
- بريد إلكتروني.
- كلمة مرور.
- استعادة كلمة المرور.

## 5.2 لوحة التحكم
تعرض بطاقات مؤشرات رئيسية:
- عدد العملاء الحاليين.
- القادمين اليوم.
- المغادرين اليوم.
- المدفوعات اليوم.
- الحجوزات النشطة.
- تنبيهات عاجلة (مثل: 20 عميل يصلون غدًا).

## 5.3 العملاء
حقول العميل:
- الاسم.
- الجنسية.
- رقم الجوال.
- رقم الجواز.
- عدد المرافقين.
- تاريخ الوصول.
- تاريخ المغادرة.
- حالة الحجز.
- حالة الدفع.
- QR Code.

العمليات:
- إضافة/تعديل/حذف عميل.
- البحث والتصفية (حسب تاريخ الوصول، الحالة، المندوب).

## 5.4 الباقات
أمثلة باقات:
- عمرة اقتصادية.
- عمرة VIP.
- عمرة رمضان.
- حج VIP.

كل باقة تشمل:
- السعر.
- الفندق.
- النقل.
- عدد الأيام.

## 5.5 الفنادق
- اسم الفندق.
- عدد الغرف الكلي.
- الغرف المشغولة.
- الغرف المتاحة (محسوبة).

## 5.6 النقل
- نوع الباص.
- السائق.
- عدد المقاعد.
- الرحلة.
- الوقت.

## 5.7 المدفوعات
- إجمالي المدفوع.
- المتبقي.
- نوع العملية (دفعة أولى / تحويل بنكي / كاش).
- حالة الدفع.

## 5.8 المندوبون
- القادمين اليوم.
- المستلمين.
- المهام المفتوحة.
- سجل النشاط.

## 5.9 الرسائل
تكامل واتساب/SMS لقوالب:
- تأكيد الحجز.
- تذكير الوصول.
- بيانات الفندق.
- رقم المندوب.

## 5.10 التقارير
- الأرباح الشهرية.
- أفضل الباقات.
- عدد العملاء.
- نسب الإشغال.
- إجمالي الديون.

## 6) متطلبات غير وظيفية

- واجهة عربية RTL كاملة.
- تصميم فاخر (أبيض + أخضر + ذهبي خفيف).
- دعم ممتاز للموبايل (Responsive).
- أمان: JWT + صلاحيات على مستوى الموارد.
- نسخ احتياطي يومي للبيانات.

## 7) الباقات التجارية (الاشتراكات)

### الأساسية — 299 ريال/شهريًا
- حتى 100 عميل.
- حتى 2 مستخدم.
- وظائف إدارة أساسية.

### الاحترافية — 799 ريال/شهريًا
- حتى 500 عميل.
- تكامل واتساب.
- تقارير متقدمة.
- حتى 8 مستخدمين.

### الشركات — 1999 ريال/شهريًا
- عملاء غير محدودين.
- فروع متعددة.
- صلاحيات متقدمة.
- دعم أولوية.

## 8) سيناريوهات تشغيل رئيسية

1. **إدخال عميل جديد** → ربطه بباقة → حجز فندق/نقل → إصدار QR.
2. **يوم الوصول** → يظهر العميل في لوحة المندوب → تحديث "تم الاستلام".
3. **تحصيل المدفوعات** → تسجيل دفعة → تحديث الرصيد المتبقي آليًا.
4. **تنبيهات ذكية** → تنبيه قبل يوم الوصول/المغادرة وبعد تأخر السداد.

## 9) KPIs المقترحة

- زمن تجهيز العميل (من التسجيل إلى التأكيد).
- نسبة التحصيل قبل الوصول.
- معدل الإشغال الفندقي.
- نسبة الالتزام بوقت النقل.
- انخفاض الأخطاء التشغيلية شهريًا.
