# خطة التنفيذ (90 يوم)

## المرحلة 1 (الأسبوع 1-2): التأسيس
- اعتماد الهوية البصرية RTL.
- إعداد المشروع (Frontend + Backend + DB).
- تجهيز نظام المستخدمين والصلاحيات.

## المرحلة 2 (الأسبوع 3-5): النواة التشغيلية
- العملاء + الباقات + الفنادق + النقل.
- شاشة لوحة التحكم الأولية.
- ربط الحجوزات الأساسية.

## المرحلة 3 (الأسبوع 6-7): المالية والتقارير
- المدفوعات والتحصيلات.
- تقرير الأرباح والديون.
- مؤشرات الإشغال.

## المرحلة 4 (الأسبوع 8-9): المندوب والتواصل
- واجهة المندوب اليومية.
- تكامل رسائل واتساب/SMS عبر مزود خارجي.
- قوالب الرسائل الآلية.

## المرحلة 5 (الأسبوع 10-11): الذكاء التشغيلي
- تنبيهات الوصول/المغادرة.
- تنبيهات التحصيل المتأخر.
- تحسين الفلاتر والبحث المتقدم.

## المرحلة 6 (الأسبوع 12-13): الإطلاق
- اختبار شامل UAT.
- توثيق المستخدم النهائي.
- إطلاق تجريبي مع 2-3 عملاء فعليين.

## المخرجات المتوقعة
- MVP جاهز للإنتاج.
- لوحة تقارير واضحة للإدارة.
- بنية قابلة للتوسع للباقات الاحترافية والشركات.
