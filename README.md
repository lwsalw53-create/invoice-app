# مناسك برو (Manasik Pro)

منصة SaaS لإدارة حملات الحج والعمرة الصغيرة والمتوسطة.

## محتويات المستودع

- `docs/PRD-ar.md`: وثيقة المنتج التفصيلية (عربي).
- `docs/db-schema.sql`: مخطط قاعدة البيانات المقترح (PostgreSQL).
- `docs/api-spec.yaml`: مواصفات API أولية (OpenAPI 3.1).
- `docs/implementation-plan.md`: خطة تنفيذ عملية على مراحل.

## نطاق النسخة الحالية

هذه النسخة هي **حزمة تسليم تنفيذية** جاهزة لفريق التطوير (أو أدوات low-code مثل Lovable) وتشمل:

- هيكل المنتج والصفحات.
- الأدوار والصلاحيات.
- نموذج البيانات والعلاقات.
- API مبدئي.
- خطة إطلاق MVP ثم التوسّع.

> يمكن البدء مباشرة من هذه الحزمة لبناء الواجهة ولوحة التحكم وقاعدة البيانات.
